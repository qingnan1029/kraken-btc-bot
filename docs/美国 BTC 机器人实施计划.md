# 美国 BTC 现货机器人实施计划

适用场景为实际在佛罗里达州居住、符合 Kraken 美国个人账户及美元入金条件的用户。平台采用 Kraken Pro，交易对为 BTC/USD。策略限定现货、单交易对、单持仓、无杠杆。模拟盘读取公共行情，启动无需登录交易所或提供 API Key。

## 本次实施顺序

| 步骤 | 工作 | 验收标准 |
| --- | --- | --- |
| 1. 行情准备 | 从 Kraken 官方归档提取 BTC/USD 的 4 小时 K 线，通过公共行情接口补齐到最近已收盘的 K 线。 | 覆盖至少两年，时间戳按 UTC 和 4 小时对齐，无未解释的缺口和重复。若有空档，先用官方逐笔成交确认。仅对已确认无成交的时段沿用前一收盘价，并禁用该时段的模拟成交。保存归档路径、条数、重叠区间核对和本地数据哈希。 |
| 2. 策略回测 | 用 20/60 根简单均线的交叉测试。预留完整待测数据最后 30%，固定参数。以 1,000 美元起始资金、每笔 100 美元、单边 0.80% 手续费执行。按单边 0.05% 滑点建模，并用 0.10% 压测。 | 信号只读已收盘 K 线，下一根开盘成交。记录完整回测、开发段和样本外的净收益、最大回撤、交易次数、买入持有基准。保存可复现命令和逐笔记录。 |
| 3. 实时模拟及故障演练 | 启动只读 Kraken 行情的 Freqtrade 模拟盘，验证配置、市场元数据和策略运行。单独验证行情缺失、断网或重启后系统行为。 | 可启动、可查看日志和订单数据库。区分启动验收与至少连续四周的观察期。故障场景的模拟结果写入实施报告。 |
| 4. 实盘决策 | 按下述交易表现和技术门槛作决定。 | 样本外在基准滑点及翻倍滑点下均为正，最大回撤在可接受范围内，模拟盘完成观察和对账。若不满足，保留模拟模式。符合条件后，由账户本人完成开户、入金并另行决定实盘授权。 |

## 固定策略与资金设置

- 20 根均线从不高于 60 根均线变为高于时产生入场信号，从不低于变为低于时产生退出信号。单笔投入上限为 100 美元，包含买入手续费。初版只验证均线交叉。不额外调仓，也不增加其他币种。
- 回测里样本外重新以现金起步，允许用前段 K 线预热均线。买入持有基准在窗口首个可用开盘投入相同的 100 美元，剩余现金保留，按相同费用假设结算。两种策略期末的未平仓头寸均按最后收盘价估算可变现净值，并单独标注。
- 第一版回测的 0.80% 吃单费率取自 Kraken Pro 官方第一档标准，开实盘前用账户已显示的实际费率及 BTC/USD 最小订单规则复核。0.05% 和 0.10% 是滑点试算，参考实际模拟盘口与成交偏差后再重估。
- 先采用模拟账户净值 5% 的最大回撤验收线。它是本轮筛选参数，实盘前由用户确认实际可承受损失。需要满足共计至少四周的模拟观察，以及跨越一次完整买卖、部分成交、超时和重启后对账演练。达到 5% 时在评估或运营中停止新增风险，并核对未成交订单和当前持仓。

## 四周验收与后续

| 时间 | 要检查的事 |
| --- | --- |
| 第 1 周 | 每日核对最近一根收盘 K 线、进程状态、模拟余额及日志。核对 UTC 时间。 |
| 第 2 周 | 测试公共行情中断与恢复，确认中断期间系统未生成未核实的新订单。检查日志、持久化数据库与重启后的状态。 |
| 第 3 周 | 用隔离环境演练交易超时、重复响应、部分成交和撤单。验证任何待处理订单都能按唯一标识查询、对账，再决定是否补单。 |
| 第 4 周 | 汇总信号与订单时间差、模拟成交成本和最大回撤。若尚未观察到完整买卖周期，继续观察。 |

个人实盘前应本人确认地址、账户资格与入金条件。实盘密钥只给必要的余额与订单查询、下单和撤单权限，关闭提现权限，并在部署环境中保管密钥。审核小额试单的金额、手续费、成交明细及成本基础，再决定是否继续自动执行。
